ORYX is a third-person roguelite currently being developed in Unreal Engine 5 using a hybrid C++ and Blueprint architecture.

The project focuses on fast-paced combat, meaningful progression, replayability, and scalable gameplay systems designed for future multiplayer support.

---

## Technologies

- Unreal Engine 5
- C++
- Blueprints
- Behaviour Trees
- Niagara VFX
- GitHub
- Visual Studio

---

## Current Features

### AI

ORYX serves as both a commercial indie game project and a long-term portfolio project demonstrating gameplay programming, AI systems, combat design, progression systems, and Unreal Engine development.
