## Slide 9 — Permanent Progression

**Visual:** skill tree screen screenshot (when WBP_SkillTreeScreen ships).

**Headline:** `Skill trees per class — Last-Epoch model`

Bullets:
- **1 passive tree** (linear, 20 nodes for demo / 60 full) per class.
- **5 ability trees** (cluster-shaped, 10 nodes × 3 ranks, max 15 invested) per class.
- 1 passive point per level + 1 ability point per 2 levels.
- Free respec anytime. Persists across runs in profile save.
- Class progression is per-class: playing Warrior only levels Warrior.
